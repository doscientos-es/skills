# Doscientos AI Project Starter

Este directorio es un paquete reutilizable para iniciar proyectos nuevos de Doscientos.

No se aplica automáticamente a `landing` ni a `backoffice`.

Para usarlo, copia este paquete al repositorio nuevo, incluidos los archivos ocultos (`.agents/`). A partir de ahí, describe el proyecto por chat y menciona que se sigan las instrucciones técnicas de Doscientos.

Antes de escribir código en un proyecto nuevo, lee `.agents/skills/doscientos-project-bootstrap/SKILL.md` y síguelo.

## Archivos principales

- `.agents/skills/doscientos-project-bootstrap/SKILL.md`: stack, convenciones y proceso de trabajo de Doscientos.
- `README.md`: instalación rápida para Codex y Augment.

## Regla de alcance

Estas instrucciones son para proyectos nuevos. No deben copiarse ni aplicarse retroactivamente a proyectos existentes salvo decisión explícita del equipo.
